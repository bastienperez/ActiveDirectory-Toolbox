# ActiveDirectory-Toolbox

> **These scripts are moving to [PSADDS](https://github.com/bastienperez/PSADDS).**
>
> PSADDS is a PowerShell module for Active Directory Domain Services
> administration: users, groups, computers, organizational units and domain
> infrastructure, through automation friendly cmdlets.
>
> The scripts in this repository are being migrated there one at a time. Nothing
> is removed from here for the moment, so anything you already rely on keeps
> working. New work happens in PSADDS, and once a script has moved, the module
> version is the one to use.

Some scripts for Active Directory reporting, plus a few computer reports.
